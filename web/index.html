玩法指南

一、起源

数独（Sudoku）的前身是 18 世纪瑞士的“拉丁方块”。现代形态由美国建筑师 Howard Garns 于 1979 年设计，1984 年由日本公司 Nikoli 命名为“数独”（读作 Su-doku，意为“数字必须单独”，即每个数字在单元内唯一）。1997 年传入欧美后风靡全球，成为最流行的逻辑益智游戏之一。

二、玩法与规则

在一个 9×9 的方格中，已预先填入部分数字（称为“题目”或“提示数”）。你的目标：把剩余空格填满，使每一行、每一列、每一个 3×3 的粗线宫格内都恰好包含数字 1–9 各一次，不重不漏。

  • 共有 9 行、9 列、9 个宫，每个单元 9 格。
  • 最终每个单元都必须含 1–9 且不重复。
  • 题目保证有且仅有一个解，靠纯逻辑推理即可填满，无需猜测。

凯利仓位计算

公式：f* = (b·p − q) / b　（b = 盈亏比 = 盈利÷亏损，p = 胜率，q = 1 − p）

四档含义：保守 / 平衡 / 进取 / 满仓 = 全凯利的 1/4、1/2、3/4、1。全凯利在数学上使长期复利增长最快，但对胜率与盈亏比的估计误差极敏感、回撤巨大，实践中普遍使用其分数档。

Dashboard.tsx 
import { useState, useEffect } from 'react';
import { fetchOrders } from '@/api/orders';

export default function Dashboard() {
  const [orders, setOrders] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchOrders().then((res) => {
      setOrders(res.data);
      setLoading(false);
    });
  }, []);

  return (
    <section className="panel">
      <h2>订单概览</h2>
      {loading ? <Spinner /> : <Table rows={orders} />}
    </section>
  );
}
